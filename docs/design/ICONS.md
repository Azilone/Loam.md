# Loam icons: inventory

Every symbol the app draws, found in the code (`App/Sources`, `Sources`). All are SF Symbols (Phosphor, which a theme
could pick, is gone), and the sidebar's are drawn one by one in the folder's style (`SidebarGlyph`)
(drawn one by one, as the folder is). Folders are drawn by `AnimatedFolderIcon`; the print themes keep their
illustrations (`PrintIllustration`).

- **211 glyphs drawn by the app** (226 names with their `.fill` variants).
- **73 more** offered only in the folder icon picker (the user's choice, not part of the UI).
