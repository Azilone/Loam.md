# The onboarding's serif

The onboarding's titles use Fraunces (SIL Open Font License 1.1), the serif of the design boards. Its files go here,
with their licence: `Fraunces[SOFT,WONK,opsz,wght].ttf`, `Fraunces-Italic[SOFT,WONK,opsz,wght].ttf` and `OFL.txt`,
from https://github.com/google/fonts/tree/main/ofl/fraunces. `OnbType` registers every `.ttf` here; without them the
titles use the system's serif.
