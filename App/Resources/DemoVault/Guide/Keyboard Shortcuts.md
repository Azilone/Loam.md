# Keyboard Shortcuts

You rarely need the mouse. Learn the first three and the rest comes by itself.

## Start with these

| Keys | What it does |
|:-----|:-------------|
| `⌘P` | **Command palette**: every action in Loam, searchable |
| `⌘O` | Open a note by its name |
| `⇧⌘F` | Search in all your notes |

## Notes and days

| Keys | What it does |
|:-----|:-------------|
| `⌘D` | Open today's note |
| `⌘N` | New note in a new tab |
| `⇧⌘U` | View the Markdown source of the note |
| `⌘J` | Ask the assistant |
| `⇧⌘R` | Record a meeting or a voice note |

## Tabs

| Keys | What it does |
|:-----|:-------------|
| `⌘T` | New tab |
| `⌘W` | Close tab |
| `⇧⌘T` | Reopen closed tab |
| `⌘[` · `⌘]` | Back · forward |
| `⌃⇥` · `⌃⇧⇥` | Next · previous tab |

## In a mind map

Open [[Plan a Weekend Away]] and try `Tab` (new topic), `⌘↑` `⌘↓` (move a topic), `⌘.` (fold a branch), `⌘0` (fit the map).

## Make them yours

Every shortcut can be changed in **Settings > Shortcuts**. If you forget one, `⌘P` shows it next to the command.
