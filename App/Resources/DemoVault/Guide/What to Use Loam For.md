# What to Use Loam For

One notebook, many uses. Pick one, open the example, and copy how it is built.

## A journal
Press `⌘D` every day. Write freely, add tasks with `- [ ]`.
Example: [[2026-10-29]]

## A project with a task board
A folder with a note for the project and one note per task. The board comes from the `status` property.
Example: [[Moving]] · the list of all projects is `Projects/Projects.base`

## A reading list or any collection
Notes with properties, shown as a table or a gallery.
Example: `Reading/Reading.base` · [[Dune]]

## Meetings
Record, get the transcript, a summary and a mind map in the same folder. `⇧⌘R` starts.
Example: [[Meetings/2026-10-27 1000 Birthday Planning/Summary]]

## Thinking out loud
A mind map to sort an idea, a board to see it with images and links.
Example: [[Learn the Piano]] · `Boards/Lisbon Trip Plan`

## Habits
One note per habit, a streak that grows.
Example: [[Walk]]

## A personal wiki
Link notes with `[[double brackets]]`, then open the graph view to see how they connect.
Example: [[Trip to Lisbon]]
